- `lib/ui/session.js` — `createSession(name, root)` gains an optional `root` argument; new private `writeSpawnEvent()` helper appends a `run.spawn` event (matching `emit-event.sh`'s wire shape) to `${root}/.concertino/runs/${ticket}/events.jsonl`, called from `spawn()` right after `respawn-window` succeeds, only when `root` was supplied. Never throws — wrapped in try/catch.
- `lib/ui/watch.js` — the single `createSession(...)` call site now passes `root` through.
- `lib/ui/reducer.js` — `emptyRun()` gains `spawnedAt: null` and `startingMs: null`; `applyEvent()` gains a `run.spawn` case (sets `spawnedAt` only, deliberately not added to `TIER2_KINDS`/`TIER3_KINDS`); `reduce()` derives `startingMs` from `spawnedAt`/`startedAt`/`endedAt`/`now`, mirroring the existing `elapsedMs` derivation.
- `lib/ui/screens/fleet/rows.js` — `statusLine()`: telemetry-`'none'` branch now distinguishes "starting Ns" (live window, known `spawnedAt`) from "no telemetry"; the failed branch distinguishes "failed to start" (telemetry `'none'`) from "window exited"; the elapsedMs duration segment is now skipped entirely when telemetry is `'none'`. `renderFinishedRow()` gets the same "failed to start" vs "window exited" split.
- `lib/ui/screens/drilldown.js` — `elapsedText()` gets the same "failed to start"/"window exited" split, plus a new "starting · Ns" branch ahead of the `started HH:MM` fallback; `headerLines()`'s `phaseRight` renders "starting…" instead of "no telemetry" for a live, pre-`run.start` window with a known `spawnedAt`.
- `test/session.test.js` — new tests: `spawn()` writes a `run.spawn` line to `<root>/.concertino/runs/<ticket>/events.jsonl` with the right `kind`/`ticket`/`t`/`role` fields when a `root` was supplied; a session created without `root` writes nothing.
- `test/reducer.test.js` — new tests: a run whose only event is `run.spawn` reports `telemetry: 'none'` with `spawnedAt` set; `startingMs` reflects `now - spawnedAt` while `startedAt` is null; `startingMs` reverts to `null` once `run.start` also lands.
- `test/fleet.test.js` — new tests: a live, telemetry-`'none'` run with `spawnedAt` renders "starting" (not "no telemetry"); a dead, telemetry-`'none'`, no-`endStatus` run renders "failed to start" (not "window exited").
- `test/drilldown.test.js` — new tests: same "starting…"/"starting · Ns" vs "no telemetry" split for `headerLines()`/`elapsedText()`; a run predating this feature (no `spawnedAt`) still renders "no telemetry"; a dead run with no `run.start` reads "failed to start".
- `test/reap.test.js` — new regression tests: a `run.spawn`-only run (no `run.end`) is never selected for reaping, for both an alive and a dead window.
- `test/retention.test.js` — new regression test: a `run.spawn`-only run's log is never eligible for pruning regardless of file age.
