- `lib/ui/watch.js` — replaced the hash-based idle tracking (`idle` Map, `hash()` helper, `IDLE_SAMPLE_MS`/`lastSample`/`takeSample` gate, per-window `session.capture(w.ticket)` call) with a stateless `idleMsFromActivity(activity, now)` helper, exported for tests; `sampleWindows()` now calls it for every alive window on every poll using `w.activity` from `session.listWindows()`.
- `test/watch.test.js` — imports `idleMsFromActivity` and adds unit tests: activity advancing between calls yields a smaller idleMs immediately; content can never affect the result (structural proof, no content argument); a fresh process's first call returns the full elapsed time (restart-survival); and the `activity == null` fallback returns `0`.
