- `lib/ui/watch.js` — CON-17 fix. Replaced the steady-state `\x1b[2J\x1b[H` full-screen clear with a pure `buildFrame(text, cols, prevLineCount)` helper that homes the cursor, pads every line to visible column width via `format.js`'s `padTo` (never raw `.length`), and blanks any leftover trailing rows when a frame shrinks. Entered the alternate screen buffer (`\x1b[?1049h`) once at startup before the first `draw()`, and exit it (`\x1b[?1049l`) exactly once from `quit()`, replacing `quit()`'s old `clear()` call (removed entirely — the two must not coexist). `doAttach()` now suspends the alternate buffer before handing the terminal to `tmux attach` and restores it in the same `finally` that already restores raw mode, via a small extracted `attachAndRestore(fn, restore)` helper so "attach throws, restore still runs" is unit-testable. Added a `process.stdout.on('resize', ...)` listener that triggers an immediate `draw()`. Added an idempotency guard to `quit()` (`if (quitting) return;`) — probed and confirmed piped stdin fires both `'end'` and `'close'`, which without the guard double-invoked `quit()` and double-wrote `\x1b[?1049l`.
- `test/watch.test.js` — new. Unit tests for the pure, exported `buildFrame`/`attachAndRestore`/escape-sequence constants: no `\x1b[2J` ever, cursor-home prefix, visible-width-aware padding of a coloured (ANSI) line (task 5.1a), shrinking-frame trailing-row blanking (task 5.3), and `attachAndRestore` running its restore callback on both a normal return and a throw (task 3.2 / design.md Decision 4).
- `test/scripts/watch-smoke.test.sh` — extended with real end-to-end byte-level assertions against the actual running dashboard (real tmux, real process, real stdout bytes) across every exit path (`q`, `echo q` with trailing newline, immediate EOF, and around a real `attach` attempt via Enter): no `\x1b[2J` anywhere, and the alternate-buffer enter/exit counts match exactly what each path is expected to produce (1/1 for a plain quit path, 2/2 around an attach attempt, since tmux fails fast with `open terminal failed: not a terminal` against non-tty stdout/stdin, exercising the suspend/restore pair without hanging).
