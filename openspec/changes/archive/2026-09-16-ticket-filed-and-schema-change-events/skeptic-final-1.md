### Why this is a real AC1 miss, not a nitpick

CON-191's motivating incident (CON-128) is "a local patch to a rendered copy in a consuming repo, invisible to framework history." `lib/auditor-lease.sh` is exactly that shape of file — rendered byte-for-byte from `core/scripts/lib/auditor-lease.sh`, executed as part of every `emit-event.sh` call via `source`. A patch to it (e.g. neutering `lease_release()`, or altering the escalation-write path it also touches) is indistinguishable, from this repo's event log, from an unpatched instrumentation — the digest never moves, so `schema.change` never fires and `instrumentation_digest` on `run.start` is silently wrong (it excludes files that are part of the executing instrumentation). This directly fails: "A local patch to a rendered script in a consuming repo is detectable from that repo's event log alone" — it is detectable only for scripts at the top level of `scripts/concertino/`, not for anything under `scripts/concertino/lib/`.

Design.md Decision 3 justifies scope choices ("why not sync time only", "why not core/", "why not per-script hashes") but never states or defends the top-level-only restriction, and Decision 12's mutation-proof requirement was never exercised against a `lib/*.sd` mutation to surface this. Evaluator's PASS and the design-gate skeptic's CONFIRM both predate or didn't probe this; I am not deferring to either.

### Verdict: REFUTE
