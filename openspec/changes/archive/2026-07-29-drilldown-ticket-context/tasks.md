## 2. Ticket text resolution

- [x] 2.1 Create `lib/ui/ticket-text.js` exporting `resolve(root, ticket, cache)`: first tries reading `<root>/.concertino/runs/<ticket>/evidence/ticket.md` (matching `persist-evidence.sh`'s deterministic destination path); on a missing/unreadable file, OR a readable file whose parsed title is blank after trimming, falls back to `cache.tickets.find((t) => t.identifier === ticket)`; returns `{ title, description } | null` (null only once both sources are exhausted). Never throws — mirrors `cache.js#read`'s own "malformed degrades to empty" contract.
- [x] 2.2 Within `ticket-text.js`, parse `ticket.md`'s title from its first non-empty line via `/^#\s*(?:\S+:\s*)?(.+)$/` (falling back to the raw first line as title if it doesn't match `# ...` at all — a badly-shaped title line is still used, not treated as a reason to fall back to the cache — design.md Decision 3). Scope the description to the content of the first `## Description` heading found (case-insensitive), up to the next `##`-level heading or end of file; if no `## Description` heading exists at all (a `ticket.md` predating this change), fall back to the content between the title and the first `##` heading found (or the whole remainder, if there are no `##` headings). Never include sections other than the description-scoped one (e.g. `## Acceptance Criteria`, `## Metadata`) in the returned description.
- [x] 2.3 `test/ticket-text.test.js`: persisted-file-preferred-over-cache; cache-used-when-no-persisted-file; both-absent returns `null`; title parsing for a well-formed `# CON-1: Some Title` first line; title parsing for a first line that doesn't match the `#`-heading shape at all (uses the raw first line as title — does NOT fall back to the cache); an unreadable/missing `ticket.md` file falls back to the cache; description scoped correctly to `## Description` when other sections (`## Acceptance Criteria`, `## Metadata`, etc.) follow it, excluding their content; description falls back to pre-first-heading prose for a `ticket.md` with no `## Description` heading at all; a persisted file that is empty/whitespace-only (blank title after trim) falls back to the cache rather than rendering an empty title/description.
