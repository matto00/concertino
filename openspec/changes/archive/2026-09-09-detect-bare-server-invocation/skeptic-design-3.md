### Non-blocking notes
- The spec's "Process identity cannot be determined" degrade scenario enumerates no-pid / unreadable-cwd / non-local host but does not name the **multiple-pids** case, which design.md Decision 2 does. The requirement sentence ("when a single local pid can be found") gets an implementer to the right answer, but adding "or more than one pid is listening" to that scenario's WHEN would make the contract match the design exactly.
- Implementation caution for 1.1: `lsof -t` dedupes pids, but the `/proc/net/tcp{,6}` fallback can yield the same pid twice for a dual-stack listener (node binds `::` by default). Dedupe pids before applying the "exactly one" test, or the fallback path will silently degrade the check. Task 2.2's RED-then-GREEN requirement should catch this if it happens, at least on the `lsof` path.
- Per-block listeners in 1.3 should be killed before each block's trailing `rm -rf "$REPO"` (or simply registered in the existing EXIT trap); a listener whose cwd directory is deleted is harmless here but makes failures confusing.
