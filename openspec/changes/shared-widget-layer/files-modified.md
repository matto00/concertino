## Flagged for the evaluator/orchestrator (not a silent scope decision)

- **`escalation.js`'s "context" block has no header/label to migrate.** Its own comment (line ~159 pre-change) states this is deliberate: "Degrade honestly when there is none: no label, no empty frame, identical to pre-change output" — a load-bearing CON-11 design decision. Task 4.7 ("apply sectionHeader to escalation.js's question/context headers") has no design.md line-level citation for this screen (unlike fleet's explicit `sections.js:136,153,180`), so I did not invent a new "CONTEXT" label; I only routed the screen's one existing header-shaped line (tag+phase) through `sectionHeader` as a passthrough (no icon — `tag` is already STATUS_COLOUR-governed, matching fleet's own status-governed carve-out for NEEDS YOU/RUNNING/FAILED/DONE).
- **`launchpad.js` was not touched**, even though design.md's Decision 5 cites `launchpad.js:318`'s empty-state wording as one of `emptyState()`'s two shape exemplars. `launchpad.js` is not in proposal.md's "Impact: Affected code" file list, so I treated the citation as documentation of the widget's target *shape* only, not a mandate to touch that file's code in this change.
- **Pre-existing icon+label inline compositions outside this ticket's enumerated scope were left as-is**: `lib/ui/screens/drilldown.js`'s four panel titles (`icons.ticket`/`icons.timeline`/`icons.gates`/`icons.evidence` + label), `lib/ui/screens/launchpad.js`'s `epicsTitle`, `lib/ui/ticketDetail.js`'s DESCRIPTION/COMMENTS headers, and `lib/ui/controllers/drilldown.js`'s `docTitle` composition. design.md's Decision 4/Context section enumerates exactly fleet's three existing inline compositions as needing migration (plus the six screens with no coverage) — it does not name any of these four as consumers to migrate, and none of them appear in proposal.md's Impact file list (`lib/ui/controllers/*.js` is absent from that list entirely). Migrating them would satisfy dashboard-iconography's spec.md text more literally but exceeds tasks.md's reviewed scope.
