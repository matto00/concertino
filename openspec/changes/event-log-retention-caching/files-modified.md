- `config/concertino.schema.json` — added `dashboard.retentionDays` (integer, minimum 1, default 30).
- `docs/dashboard.md` — documented `retentionDays` in "Configuration", added a "Retention" subsection under "Where the data lives" covering `concertino prune` / the startup prune, and added `concertino watch` help text noting the startup prune.
- `lib/ui/store.js` — `readAll(root, cache)` now accepts an optional cache (via new `createEventsCache()`); when a cache is passed, reads incrementally from a per-ticket stored byte offset instead of re-parsing the whole file every call, evicts entries for tickets no longer on disk, and handles truncation/rewrite by resetting the cache entry. `readEvents` (the uncached full-reparse primitive) is unchanged. Omitting the cache argument keeps the original full-reparse behavior.
- `lib/ui/retention.js` (new) — `isEligible`, `hasRunEnd`, `resolveRetentionDays`, and `prune(root, opts)`: removes the whole `.concertino/runs/<TICKET>/` directory for runs that are both terminal (`run.end` logged) and past the retention window; a run with no `run.end` is never eligible regardless of age; `dryRun` computes the same report without touching disk.
- `lib/ui/watch.js` — creates one `store.createEventsCache()` instance before the poll loop and passes it to every `store.readAll(root, cache)` call; runs `retention.prune(root, config)` once, best-effort (wrapped in try/catch), before the poll loop starts.
- `bin/concertino` — new `concertino prune [--dry-run] [--config=PATH] [--out=DIR]` subcommand (loads config the same way `cmdWatch` does, resolves `dashboard.retentionDays`, calls `retention.prune`, prints what was removed/would be removed) and its help text entry.
- `test/store.test.js` — new tests for `readAll(root, cache)`: reference-equality on an unchanged file (no re-parse), incremental pickup of appended lines with malformed-line accounting, safe handling of a truncated/rewritten file, cache eviction for a removed ticket, and confirmation that the no-cache-argument call path is unchanged (fresh array every call, no cross-call persistence).
- `test/retention.test.js` (new) — eligibility predicate coverage (no `run.end` never eligible regardless of age; terminal+old is eligible; terminal+recent is not), `prune()` removing only eligible run directories, `dryRun` performing no filesystem changes, the 30-day default applying when unset, and default resolution from a full config-shaped `opts` object (as `watch()` passes it).
